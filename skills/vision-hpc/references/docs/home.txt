# Welcome to VISION Documentation

VISION is a Texas A&M University System (TAMUS) GPU-accelerated computing platform supporting large-scale research, data-intensive workflows, and AI/ML applications across all TAMUS institutions.
## Current Status: General Availability【11†​】

  * Access requires completing an application and approval by TAMUS governance
  * Users must run GPU-enabled workloads and provide feedback
  * Features and tools are evolving
